An entry for the [make.fun bounty "The Internet in One Word"](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b): describe the whole internet in a single word.

The word is **Tabpocalypse** — tab + apocalypse. Every tab you ever opened, still open, still screaming, multiplying faster than you can close them. That is the entire internet: not one site, not one app, just the endless sprawl of tabs you swore you would read later.

Why this word: it is funny on its own, it fits the internet as a whole rather than one corner of it, and it surprises — a portmanteau that lands in a single beat.

## Run it

```sh
node main.ts
```

This writes the entry word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
